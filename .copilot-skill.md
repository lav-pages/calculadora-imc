# Copilot Skill: Calculadora IMC

## Objetivo operativo
Implementar una calculadora IMC de una sola página con clasificación de resultado y validación clara.

## Reglas de implementación
- Fórmula: `IMC = peso_kg / (altura_m^2)`.
- Soportar altura en `cm` y `m`.
- Validar `peso > 0` y `altura > 0`.
- Normalizar altura automáticamente para entradas ambiguas:
  - si unidad es `m` y valor >= 100, interpretar como `cm` y convertir a metros;
  - si unidad es `cm` y valor < 3, interpretar como `m`.
- Mostrar IMC redondeado + categoría (OMS).
- No persistir datos del usuario.

## Casos mínimos de prueba
- `70kg` y `1.75m` -> IMC cercano a `22.86`.
- `70kg` y `175` con unidad `m` -> normalización automática a `1.75m`.
- `70kg` y `1.75` con unidad `cm` -> normalización automática a `1.75m`.
- Altura/peso inválidos -> error visible.
- Misma entrada produce mismo resultado.
